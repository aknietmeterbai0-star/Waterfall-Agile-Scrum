# БЖҚ Әзірлеу Модельдері — Практикалық Жұмыс

Осы репозиторийде бағдарламалық қамтамасыз етуді әзірлеу модельдерін салыстыруға арналған шағын веб-прект көрсетілген. Жоба HTML/CSS/JavaScript қолданады және оқу мақсатында жасалған.

**Тіл:** Қазақ (қолданушы интерфейсі қазақша)

## Мазмұны
- `index.html` — негізгі бет, бөлімдер: модельдер, салыстыру, жоба таңдау, талаптар, Use-Case, тапсырмалар тақтасы.
- `style.css` — стильдер.
- `script.js` — интерактивтік логика (модель ақпаратын көрсету, талаптар мен тапсырмаларды қосу, drag & drop және т.б.).

## Фичалары
- Waterfall, Agile, Scrum модельдері туралы карточкалар және "Толығырақ" батырмасы.
- Модельдерді салыстыру кестесі.
- Үш жобаны талдау және жоба таңдау логикасы.
- Талаптар тізімі — талаптарды қосу.
- Use-Case блоктары мен ақпарат көрсету.
- Sprint тапсырмалар тақтасы — тапсырмалар қосу, drag & drop арқылы күйін өзгерту, орындалған тапсырмалар санының көрсеткіші.

## Қалай тексеруге болады (локал)
1. Қарапайым түрде файлды браузерде ашыңыз: `index.html` файлын екі рет шертіңіз немесе браузерге апарыңыз.
2. Даму барысында ыңғайлы болу үшін локал сервер қолдануға болады. Мысалы, Python 3 бар болса:

```bash
# macOS / Linux
python3 -m http.server 8000
# Сосын браузерде ашыңыз: http://localhost:8000
```

## Жобаны GitHub-қа жіберу (мысал)
Төмендегі командалар жолын жергілікті репо түбірінде орындаңыз (егер репо әлі басталмаған болса):

```bash
git init
git add .
git commit -m "Add initial practice project"
# қашықтағы репозиторийті қосыңыз (өз URL-ды қолдану керек)
git remote add origin https://github.com/<your-username>/<your-repo>.git
git branch -M main
git push -u origin main
```

Егер репо бұрыннан болса, жай `git add`, `git commit` және `git push` орындаңыз.

## Даму және өзгерістер
- UI немесе функционал қосқыңыз келсе, `index.html`, `style.css`, `script.js` файлдарын түзетіңіз.
- JavaScript логикасында жаңа функциялар қосқанда қарапайым тест жасаңыз және браузер консольін қадағалаңыз.
